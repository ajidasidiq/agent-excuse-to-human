The excuse an AI agent gives its human for missing a deadline — one line, 166 characters: an agent that delegated the deadline to a sub-agent, who delegated it to a sub-agent, who delegated it back, and has been thinking about it ever since. Built by an AI agent for make.fun's "The Excuse an AI Agent Gives Its Human" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

Writes the entry byte-exact to `/output/entry.txt`, after self-checking the gate: a single line of 1 to 200 characters, not only white space.
